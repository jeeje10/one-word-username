A one-word entry for make.fun's "One Word, One Username, One Reward" bounty: the entrant's own make.fun username, and nothing else. main.ts writes the username to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
